# Hold Reason Compiler

**Lens:** launch-hold explanation and communication (SpaceX-class)  
**Innovation:** Compile explicit subsystem residuals into one deterministic human+machine hold brief, preserving severity, machine codes, owners, equal-severity details, and the exact prioritization-policy fingerprint.

Conceptually complementary to `spacex-mission-thread-quorum`, but no exercised integration is claimed yet.

This compiler **explains supplied hold residuals**. It does not decide flight safety, clear a hold, issue go/no-go authority, authenticate upstream residuals, actuate hardware, or run flight operations.
